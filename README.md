Sorting Visualizer
About the Project
Sorting Visualizer is a web-based application that helps users understand how different sorting algorithms work through visual animations. Instead of just displaying the sorted array, it shows how elements move and change their positions during the sorting process.

This project is developed using HTML, CSS, and JavaScript.

Features
Visual representation of sorting algorithms.
Animated movement of array elements.
Supports multiple sorting algorithms.
Easy-to-use interface.
Helps beginners understand sorting techniques.
Allows users to observe the sorting process step by step.

Sorting Algorithms
Bubble Sort
Selection Sort
Insertion Sort
Merge Sort
Quick Sort

Technologies Used
HTML:For creating the structure of the application.
CSS:For designing and styling the interface.
JavaScript:For implementing sorting algorithms and animations.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Locate the `index.html` file.
4. Right-click on `index.html`.
5. Select Open with Live Server.

The Sorting Visualizer will open in your web browser.
